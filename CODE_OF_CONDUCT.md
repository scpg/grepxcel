# Code of Conduct

## Our standard

This project adopts the **[Contributor Covenant, version 2.1][cc]** as its code of
conduct. The full, canonical text is maintained by the Contributor Covenant
project and is available here:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: everyone participating in this project — issues, pull requests,
discussions, and any other space — is expected to be respectful, welcoming, and
considerate. We want a harassment-free experience for all contributors regardless
of background or identity. Maintainers may remove or reject contributions, and
restrict participation, that are not aligned with this standard.

## Reporting

If you experience or witness behaviour that violates this standard, please report
it privately to the maintainer **[@scpg](https://github.com/scpg)**.
